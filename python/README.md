# capsule-engine

The thin single-node enforcement layer for AI agent actions: the guard, append-only fold
compute, the Terms Packs runtime, policy activation, and the local
console/report/bundle-viewer runtime.

```
pip install capsule-engine
```

It installs the `capsule_engine` package and the `capsule-engine` command. Its dependencies,
`agent-action-capsule`, `checkpointed-local-log`, `capsule-emit`, `jsonschema` and `pyyaml`, come
from PyPI.

The documentation, the Go module and the shared conformance vectors are in the repository:
<https://github.com/action-state-group/capsule-engine>.
